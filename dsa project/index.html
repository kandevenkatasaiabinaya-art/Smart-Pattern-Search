PROJECT EXPLANATION

Why These Algorithms?

KMP
01
PATTERN SEARCHING

Knuth–Morris–Pratt

KMP performs exact pattern matching efficiently by using an LPS array. When a mismatch occurs, the algorithm avoids repeating comparisons that are already known.

Why we use it Fast exact topic searching.
TIME O(n + m)
SPACE O(m)
DP
02
FUZZY MATCHING

Edit Distance

Edit Distance calculates the minimum number of insertions, deletions and substitutions required to convert one string into another.

Why we use it Handles spelling mistakes and approximate topic searches.
TIME O(n × m)
SPACE O(n × m)
BST
03
STRUCTURED LOOKUP

Binary Search Tree

Topics are organized in a hierarchical structure. Comparisons determine whether the search continues to the left or right subtree.

Why we use it Efficient topic lookup and source location.
AVERAGE O(log n)
WORST O(n)
TF
04
DOCUMENT ANALYSIS

TF-IDF + Cosine Similarity

TF-IDF assigns weights to terms according to their importance. Cosine Similarity compares document vectors to determine how closely related they are.

Why we use it Finds related DSA documents and topics.
OUTPUT Similarity %
